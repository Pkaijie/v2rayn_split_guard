v2rayN 分流助手 3.2.0 — Qt Widgets / Windows 64 位便携版

双击 V2rayNSplitGuard.exe 启动，无需安装 Python、Conda、Qt 或 Python 依赖。
首次启动会释放内置运行库，可能需要数秒。常规启动只需要这一个 EXE。
分享时请保留完整分发包中的说明、licenses 和 sources；这些资料不参与常规运行。

新版保留深青侧栏、浅色卡片，使用标准系统标题栏和 Qt 原生控件。
状态总览、备份恢复、诊断日志、高级设置均在主窗口内通过侧栏切换。
设置表单是草稿，切页会保留；保存后生效，放弃修改恢复原设置。

路由操作会立即显示进度窗口，包含当前阶段及已用时间。
只读检查可以取消；实际变更会等待完成或回滚，不能强行中断。
没有路由变更时重新核对节点、DNS、网关及两个路由存储，跳过重复写入。
管理范围更新前仍会备份；完全无需更新时不会生成重复备份。

第一次使用：
1. 启动已配置好节点的代理客户端，并连接所需网络。
2. 在高级设置点击运行配置路径下的“自动检测”，核对后保存。
   多候选时选择并采用。支持手动选择 YAML、JSON、JSON5 或 TOML 配置文件。
3. 填写实际 WLAN 网卡名和公司连接名称，网关留空自动读取，保存。
4. 回到状态总览立即检查，选择要维护的出站，核对节点地址、当前端口和协议。
5. 点击“应用 / 修复路由”，确认预览中的目标、网卡、旧/新网关和持久化后再执行。
6. 再次检查并测试代理。自动模式读取本机 SOCKS5 / 混合监听，也可在高级设置手动指定。

新增独立核心支持 Hysteria 2、NaiveProxy、TUIC、Juicity、Brook、OverTLS、ShadowQUIC。
Brook 在高级设置选进程，重启 Brook 后重新检测并保存。动态选路需确认第一跳。

使用 Clash / Mihomo 的代理组时，请在客户端确认当前连接的第一跳，再选择对应节点。
客户端自动切换节点后，请更新选择。外部节点提供者的第一跳可手动填写。

路由表检查 IPv4 和 IPv6，长值可悬停查看，支持纵横滚动和 Ctrl+C 复制。
“路由分流正常”是系统选路证据，HTTPS 成功是测试请求可用证据，均不是抓包出口证明。
工具只诊断与维护，不阻止流量，不修改默认路由、接口优先级、DNS、防火墙或 v2rayN 设置。

后台检查默认约 15 秒一次；每 60 秒测试代理需主动开启。
未读提醒只合并更新，不堆叠或排队补弹。“知道了”后持续故障不重复提醒。
点击主窗口关闭按钮可选择直接退出或最小化；“不再提示”可记住选择。
高级设置顶部可更改关闭行为。托盘不可用时最小化到任务栏。
退出会停止监测，并等待正在进行的任务完成或回滚。

数据目录保持 %LOCALAPPDATA%\V2rayNSplitGuard，兼容旧版设置、日志和 JSON 路由备份。
备份恢复页选择本工具备份、检查并预览，确认后才恢复；不会覆盖并发的外部路由修改。
分享前核对本机诊断信息，节点、网关和公网 IP 不应随开发目录一起发布。

回退时先退出当前版本，再启动旧版。旧版可继续读取原数据；如已切换到 YAML，请重新选择 JSON 或手动输入节点。
系统目标为 Windows 10/11 64 位；诊断需系统自带 PowerShell/NetTCPIP、netsh、curl。
代理客户端、节点和订阅需自行准备。本程序不自动安装开机启动。

第三方 Qt/PySide6 组件许可及对应源代码随包提供，详见 licenses/REBUILDING.txt。
允许替换兼容的用户修改版 Qt/PySide6 动态库，正常使用无需执行这些开发步骤。
